Task-2: API Data Fetching & Filtering 🚀


This project is part of my internship tasks at InternSpark.

It demonstrates how to interact with external web APIs using Python, handle JSON data, and implement filtering logic.

Features

API Integration: Uses the requests library to fetch real-time university data from an external API.

JSON Parsing: Correctly parses and processes JSON responses into readable data.

Dynamic Search: Allows users to filter results by country name.

Professional Formatting: Displays results in a clean, user-friendly format in the terminal.
